# Rota do Lucro

Jogo incremental para Windows x64. Comece com uma barraca de pastel, automatize seus negócios e abra uma rota de exportação.

- **Campanha:** da primeira venda ao primeiro frete, com duração-alvo de 1h30.
- **Jogo Livre:** expanda a rede e invista em bônus permanentes.

Baixe o pacote em [Releases](../../releases), extraia o ZIP e abra `RotaDoLucro.exe`. O pacote inclui instruções e os avisos de licença do Godot.
